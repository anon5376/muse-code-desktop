# Muse native workspace direction

**THESIS:** Keep Muse’s execution engine and make its work, routes and requests legible in a native macOS workspace.

**OWN-WORLD:** Signal Desk: neutral charcoal regions, Muse blue for selection and focus, and amber for requests that need the user or model data-use notices. Canvas #111112, sidebar #0C0D0F, raised #1A1B1E, popover #232428, hairline #26282C, control stroke #3A3D42, text #E6E8EB, secondary #A9AEB5 and muted #9CA3AF. The proposed #767C84 tertiary text failed small-text contrast on these surfaces and is not used. Brand blue stays #2694FE; native filled controls use #0B5CAE because macOS supplies light labels. Custom send/stop controls retain blue with dark #0A1317 ink. Native system typography, flat regions, no decorative shadows, gradients or hero graphics.

**STORY:** Choose a workspace and actual model/provider/profile route, including the resolved configured default and its data-use notice. Compose a prompt or select a skill through Command-K. Read block-formatted output and tool activity. Respond to Muse’s requests explicitly in a dock above the composer. Open Files, Activity, Skills or Session in the inspector without replacing the conversation.

**FIRST VIEWPORT:** A 248-point hideable session margin and a 52-point title band. The empty view names the actual workspace, shows up to three real recent sessions and previews starter prompts inside a scroll view. Transcript prose is capped at 720 points; the composer starts with a 44-point editor and grows to 200. The inspector is 300 points wide: beside the conversation when at least 560 points remain, otherwise over the reading region, leaving the composer and request dock unobscured. Command-K opens a bounded 560 × 420 maximum palette over the reading region. The model picker is a 380 × 500-point native popover; its catalog scrolls while reasoning and the data-use notice remain visible. Goal and Activity have direct title-band controls. Required captures use actual 1280 × 820 and 980 × 640 outer windows.

**SIGNATURE:** Select a real workspace file, read its native preview, then use Add to message to insert its relative-path mention. MSP defines file mentions as text input; the app does not invent a structured mention type. Permission cards remain visible during skill browsing and file inspection. Multiple pending requests are paged in arrival order. Host choices remain verbatim; local UI never invents permission grants.

**FORM:** This remains the code-led native workspace developed under the user’s delegated design choices, now revised in response to the user-supplied Claude review. The original helper assigned the proofing-desk structure; its catalog was unavailable, so no approved comp or retained seed key exists. Signal Desk is the current local design candidate, not user design approval. No comp or catalog artifact is invented.

**STATE AND EVIDENCE:** Normal Muse catalog reads, actual isolated Muse echo turns and synthetic protocol/UI fixtures are distinguished in verification. Synthetic captures must be labeled in the window and in their captions. Native UI and source inspection do not certify live-provider tools, durable restoration or performance gains. Dock attention is implemented; system notification delivery is not claimed.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

The real Muse SVG from Muse's public website replaces the placeholder mark. scripts/GenerateIcon.swift renders the unchanged logo onto the existing charcoal tile; its original gradient is preserved. The sidebar says Unofficial desktop client, with explicit non-affiliation notices in Settings and About. docs/brand-assets.md records provenance and excludes the third-party logo from the wrapper's MIT license. Actual-window captures and recordings are local evidence, excluded from publication. The owner explicitly authorized source publication as muse-code-desktop on 2026-10-08. Design/testing acceptance remains open; promotion has not started and requires separate approval.
