# Muse Code Desktop v0.1.0

Initial public preview of the unofficial native macOS workspace for the Muse Code CLI.

**This is not the official Muse Code desktop app. It is not affiliated with or endorsed by Meta.** Muse and its logo belong to Meta.

## Install

Requires **macOS 14 or later**, **Apple Silicon**, and a working **Muse Code CLI** with an existing login (`muse login`). The CLI is not bundled.

1. Download `muse-code-desktop-0.1.0-arm64.dmg` below and verify it against the `.sha256` file.
2. Open the DMG and drag **Muse Code** to **Applications**.
3. This build is **ad-hoc signed and not notarized**. On first launch macOS may say the developer cannot be verified: right-click the app and choose **Open**, or allow it under System Settings → Privacy & Security. If Finder reports the app as damaged after downloading, run `xattr -dr com.apple.quarantine "/Applications/Muse Code.app"` once.

## In this preview

- Native SwiftUI/AppKit workspace supervising `muse serve` over JSON-RPC — no webview, no third-party dependencies.
- Session navigation, Markdown transcript, tool activity, and explicit approval/question cards that keep your configured permission policy.
- Real model/provider/profile picker with reasoning preferences and host-supplied data-use notices.
- Command-K skills and commands palette, workspace file inspector, session/goal controls.

## Verification

Built and checked on a clean GitHub Actions `macos-15` runner: release build, core and workspace suites (the real-`muse` echo checks skip when no CLI is installed — the runner has none), signature and Info.plist validation, DMG mount/install/copied-launch, and a scripted UI regression over the synthetic fixture (Markdown render, 40-line approval, palette, 1280×820 → 980×640 resize, deny, responsiveness).

## Known limitations

- Ad-hoc signature only; no Developer ID or notarization.
- Live-provider turns, real tool grants, durable session resume, and long-session stress are not covered by the fixture checks — see `docs/acceptance.md` for the open checklist.
- arm64 only; no Intel or universal build.
- Terminal-only Muse features (plugin/MCP management, login, voice) remain in the CLI.
